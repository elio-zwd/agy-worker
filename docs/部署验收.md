# 本地部署验收记录

## 2026-09-09 v0.3 多客户端架构验收

Codex 侧 stdio 进程已改为一次性 Bridge，常驻 Controller 唯一持有 Runtime、SQLite、任务、会话、取消和 artifact。公开接口名称保持为 agy_capabilities、agy_worker、agy_continue、agy_status、agy_cancel、agy_artifact_read，并继续提供两个只读 Resources。

29 个本地回归测试通过。新增真实 stdio 验收覆盖：两个 Bridge 同时 initialize 和 tools/list；A 提交后 B 查询并读取证据；全部 Bridge 退出后 Controller 仍可查询任务；两个客户端并发首次连接只产生一个 Controller；Controller 重启把未完成任务标记为 interrupted，历史 artifact 仍可读且任务不会自动重做。

Controller 由首个 Bridge 通过 Windows WMI 在 MCP Job Object 之外隐藏启动，绑定 127.0.0.1，并使用随机 Bearer 凭据、health check、启动锁和协议版本 1。Bridge 退出不会调用 Runtime.close，Controller 继续保持单任务执行槽。显式停止入口为 scripts/stop.ps1。

原故障并非 AGY 接口改名，而是每个 stdio MCP 在 initialize 前创建 Runtime；第二个进程获取 runtime.lock 失败后直接退出。v0.3 保留正确的单 Runtime 锁，解除 stdio 生命周期与 Runtime 生命周期的绑定。

日期：2026-09-08。安装目录：`D:\My\_Elio\agy-worker`。源码与脚本均保存在本机，Git 已初始化，未自动提交或上传。
